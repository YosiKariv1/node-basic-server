# Node.js Basic HTTP Server

Simple HTTP server project built as part of the **Udemy course: NodeJS - The Complete Guide**.

## ✅ Features
- GET `/` – shows form to enter username
- GET `/users` – shows a simple list of users
- POST `/create-user` – logs submitted username to the console

## 🚀 How to Run
```bash
node basic-node-server.js
```

Then open: [http://localhost:3000](http://localhost:3000)

## 🖥 Example Output
When submitting `Yosi`:
```
Username: Yosi
```
